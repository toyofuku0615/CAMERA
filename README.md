# BACKSTAGE

iPhone Safari向け服装チェックWebアプリ。React / TypeScript / Vite。黒い無地のセーターに付いた約3cm四方の白いシール・テープを対象にしています。撮影画像は端末内だけで解析します。

本改修では、**人物を認識してから服の胴体を解析**します。背景の暗さからセーターを選ぶ旧方式を廃止しました。撮影・5画面のUI・デザインは維持しています。

**実物シールとiPhone実機による改修後の精度は未測定です。背景条件ごとの9/10・8/10目標を達成したとは判断していません。** 公開参照写真のモデル推論と、実写真に白いパッチ・背景を合成した試験は、実機の受け入れ試験と区別しています。

## 起動・ビルド

Node.js 24 LTS / npm 11。APIキー、ログイン、バックエンド不要。

```sh
cd /workspace/CAMERA
npm ci
npm run dev
```

`predev` と `prebuild` が `npm run prepare:vision` を実行します。初回だけGoogle公式の固定バージョンモデルを取得し、チェックサムを検証します。ビルド環境から `storage.googleapis.com` へのHTTPS接続とcurlが必要です。以降は検証済みキャッシュを再利用します。MediaPipeのWASMはnpmからコピーし、モデルとともに**自サイトから配信**するため、アプリ実行時に撮影画像の外部送信や第三者CDNへのアクセスは発生しません。

```sh
npm run build
npm run preview
npm test
npx playwright install chromium
npm run test:e2e
```

このクラウドでは `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:e2e` を使用します。ブラウザのインストール先を変える場合は、インストールと実行に同じ `PLAYWRIGHT_BROWSERS_PATH` を指定してください。

iPhoneのカメラにはHTTPSが必要です。ViteのlocalhostやLANのHTTPアドレスは公開URLではありません。

## 維持した撮影体験

ホーム → 撮影準備 → 自動撮影 → 解析中 → 結果の5画面。フロントカメラ（`playsInline` / `muted`）、約3秒の準備＋正面・側面①・背面・側面②各6秒で約27秒。右90度ずつ回り、数字が消えるまで静止します。各方向の最後0.75秒で4枚取得します。音声が再生できなくても視覚カウントダウンで進行します。

検出枠、方向切替、画像拡大、全体再チェック、未確認方向だけの再撮影を維持しています。カメラ拒否・切断・取得失敗・ブレ・人物認識不足・モデル失敗を異物なしとして扱いません。背景を登録・指定する操作はありません。明るい室内で、逆光と手による服の遮蔽を避けてください。

## 人物を先に認識する解析

1. MediaPipe Pose Landmarker Liteを静止画像モードで実行。肩・腰ランドマークと `outputSegmentationMasks` の人物マスクを取得。
2. 肩〜腰の四角形と人物マスクの積を胴体領域にする。顔・背景を除外し、見える手・指の周囲を除外。
3. 人物に囲まれた小さいマスク穴は画像の明度に関係なく補完。白いシール自体を暗い生地マスクで除去しない。
4. 胴体内で局所的な暗い生地の平均を計算し、明暗差から白い候補を抽出。絶対輝度だけに依存せず、露出で暗く写った白も対象とする。
5. 8近傍の連結成分を作り、面積・形状・色の偏り・周囲の生地・局所コントラストを検査。
6. 最も鮮明なフレームを基準に、肩・腰の座標で移動・拡大縮小・回転を合わせ、IoUと中心距離を併用して一致を判定。
7. 1枚でしか確認できなかった候補も**低確信度で保持**。別フレームだけにある別の候補は、その実際の画像で表示する。存在しない枠を基準画像に投影しない。

通常撮影では4枚の鮮明度を評価し、上位2枚のみモデル推論を実行します（計8回）。静止フレームごとに処理してUIへ制御を返しますが、モデル推論自体はメインスレッドで同期実行されるため、iPhoneでは短い応答停止が起こり得ます。動画の常時推論は行いません。

肩・腰が不確かな場合は**人物マスクとガイドの積**で候補を探し、判定不能を明示します。人物マスクがない、人物が複数、照明や遮蔽で胴体を十分確認できない場合は再撮影を案内します。従来の最大暗領域へのフォールバックはありません。

プレビューはCSSで反転、撮影時にCanvasで一度反転し、モデル・解析・結果画像・SVG枠は同じ座標系を使います。

## モデル・依存の固定

- `@mediapipe/tasks-vision`: **0.10.32**（完全固定、package-lock.jsonあり）
- 公式モデル: **pose_landmarker_lite / float16 / 1**
- SHA-256: `59929e1d1ee95287735ddd833b19cf4ac46d29bc7afddbbf6753c459690d574a`
- 配布元: `https://storage.googleapis.com/mediapipe-models/pose_landmarker/pose_landmarker_lite/float16/1/pose_landmarker_lite.task`

モデル約5.6MiB、WASMは端末に合うSIMD／非SIMDを使用。配信には通常の圧縮・キャッシュが利用できます。モデルとWASMの生成先 `public/vision/` はGit対象外で、ビルド時に再現します。ブラウザでもモデルSHA-256を検証します。読み込みに失敗すれば撮影開始を無効化し、明示的な再試行を表示します。終了・バックグラウンド移行でモデルのグラフとカメラを解放します。

## 開発者の診断画面

開発サーバーの `/dev` にJPEG／PNGを最大8枚入力。通常の本番UIには存在しません。

- 元画像、人物マスク、実際の胴体解析マスクとポリゴン
- 白い候補、採用候補、除外候補と理由（背景・胴体外・面積・明暗差など）
- フレームごとの結果、低確信度／複数確認、モデル推論時間
- 明度、局所明度、明暗差、面積、胴体余白などの即時調整

閾値変更時はキャッシュしたランドマークとマスクで再解析し、モデルは再実行しません。設定の変更は画面内だけで、採用値は `src/config.ts` へ反映します。

## 実機で調整する値

`src/config.ts` の `DETECTION`：`brightnessThreshold`（強い白170）、`minLocalBrightness`（局所候補の最低明度110）、`contrastThreshold`（90）、`darkThreshold`（85）、`minArea / maxArea`（解析幅480pxで18 / 2600画素）、`regionMargin`（肩・腰ポリゴンを広げる割合0.025）、`minSurroundingDark`（0.75）、`minSharpness`（5）。モデルの `PERSON.maskThreshold`（0.55）、ランドマーク可視性（0.2）、胴体マスク一致（0.6）、`TEMPORAL.centerToleranceRatio`（胴体の対角長の0.035）、`minimumOverlap`（0.2）、`maxAnalyzedFrames`（2）も調整可能です。

調整前にマスクと候補除外理由を確認してください。無差別に閾値を下げると反射・肌・アクセサリーを拾います。通常の撮影設定は従来どおり `CAPTURE` で管理します。

## テストと必要な実写真

検証結果：`docs/TESTING.md`。写真の条件・記録方法・評価コマンド：`docs/PHOTO_VALIDATION.md`。

## HTTPS公開

Netlifyはリポジトリ接続後 `netlify.toml` を使用（Node24、`npm ci && npm run build`、公開先dist）。VercelはリポジトリをViteプロジェクトとして接続し `vercel.json` を使用。Root Directoryはリポジトリ直下。ビルド環境のGoogleモデル配布元への通信が必要です。CSPに `wasm-unsafe-eval` を追加し、画像は自サイト・data/blobのみ、通信は自サイトのみ、カメラ以外の権限は無効化しています。

公開後、発行された実際のHTTPS URLをiPhone Safariで開き、カメラ・日本語音声・4方向・背景移行・中止・シールの移動と除去を確認してください。本作業ではホスティングへのデプロイは行っていません。

## 制約

- 実物シール／実機iPhone／6種類の実際の背景での精度と処理時間は未検証。
- 視認できないシール、逆光、暗い服と背景が識別不能な入力、服の端、手の遮蔽、非常に小さいシールは見落とし得る。
- 明暗に基づく候補なので、白いネックレス・柄・強い反射をシールと意味的に区別できない。
- Pose Landmarkerの背面・側面の肩／腰が不安定なら人物マスク＋ガイドへ縮退し、判定不能とする。Image Segmenterの別モデルや常時動画推論は導入していない。
- 単発の高コントラスト反射も低確信度で残る場合がある。枠は必ず実際の画像で目視確認。
- 上位2フレーム以外はモデルで解析しない。必要に応じ診断画面で全画像を比較する。
- しわ・毛玉・細かな糸くず、他の色や柄の服は対象外。

ログイン、外部画像API、画像のクラウド保存、分析・追跡SDK、履歴はありません。撮影フレームと結果はメモリのみ。終了で参照とモデルグラフを破棄し、メモリ回収はブラウザに委ねます。
