# 検証記録：人物認識を利用した異物検出

実施日：2026-10-09。環境：Linux、Node.js 24.19.0、npm 11.9.0、Chromium 151.0.7922.173。MediaPipe Tasks Vision 0.10.32 / Pose Landmarker Lite float16/1（SHA-256固定）。

## 背景依存の修正

旧版でユーザーから「iPhoneで黒いセーターに貼った白いシールが検出されない」と報告がありました。撮影回数・元画像は未提供のため、旧版の失敗率や画像ごとの直接原因は未測定です。

コードからは以下の失敗条件を確認しました。

- ガイド内で最大の暗い連結領域を服としており、暗い背景につながると服の範囲が不確かになる。
- 明度170未満の白いシールは候補に入らない。
- 複数フレームでIoU>0.3を満たさない候補を削除している。

改修では人物マスク＋肩・腰の領域、局所明暗差、胴体位置合わせ＋中心距離、単発候補の保持へ変更しました。未選択フレームだけの候補は実際の画像に切り替えて確認できます。

## 実人物写真のモデル推論と写真合成試験

Googleが公開しているMediaPipeの参照写真：`https://storage.googleapis.com/mediapipe-assets/pose.jpg`。SHA-256：`c8a830ed683c0276d713dd5aeda28f415f10cd6291972084a40d0d8b934ed62b`。人物が暗いスポーツシャツと白いネックレスを身に着けている写真です。無地の黒いセーター、背面、実物の3cmシールではありません。

- 元写真でモデルが肩・腰・人物マスクを生成。胴体と人物マスクの一致は約97.9%。
- 上半身を切り出し、元モデルのマスクで背景を合成。その**合成後の画像でモデル推論をやり直した**。
- 白い10×10pxパッチを0／1／2個追加し、予測マスク・胴体・検出枠を検証。実寸3cmであるとは判断していない。
- 以下18通りの変種は同じ1枚の参照写真から作成。独立した18回の実機撮影ではない。

既存候補は元写真のネックレスです。初回の「パッチなし＝候補0」期待はこの既存物を見落として失敗したため、実写真の内容に合わせて注釈を修正しました。アルゴリズムをネックレス除去のために調整したものではありません。白い付着物の候補を意味的に「シールだけ」と区別できない制約を示しています。

モデル推論＋画素解析はこのLinux/Chromium環境でおおむね60〜215ms／画像（モデル読み込みを除く、実行条件で変動）。iPhoneの処理時間や実機精度はこの値から保証しません。検証JSONはローカル `validation-results/reference-person.json`、元の参照写真はGit対象外の `private-fixtures/reference-pose.jpg`。再現コマンドは `npm run test:e2e`。
